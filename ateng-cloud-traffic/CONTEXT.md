# Traffic Context

微服务全链路流量染色、泳道隔离与金丝雀灰度路由限界上下文，负责统一纳管微服务全域流量染色规则、双写上下文生命周期管理、Spring Cloud LoadBalancer 东西向灰度路由责任链、一致性哈希粘性百分比切流、Nacos 动态规则分级热更，以及多跳调用中的平滑降级与跨跳泳道穿透。

## Language

**Traffic Tag**:
贯穿微服务全调用链路的流量染色标记（标准标头 `X-Traffic-Tag`），用于在分布式调用拓扑中精确指示当前请求所属的灰度版本或隔离环境。
_Avoid_: 灰度标识, 环境参数, 分组标签, 流量头

**Traffic Lane**:
由具有相同流量染色标签或相同服务版本的微服务实例子集构成的逻辑隔离调用通路（分为基线默认泳道与金丝雀灰度泳道）。
_Avoid_: 灰度集群, 虚拟环境, 隔离分组

**Three-Tier Routing Chain**:
按照「业务版本隔离（Traffic Tag）➔ 拓扑机房亲和（Zone Preference）➔ 启动平滑预热加权（Warmup Weight）」严格时序级联执行的 Spring Cloud LoadBalancer 复合调度责任链。
_Avoid_: 负载均衡过滤器, 实例选择器链, 级联路由

**Lane Continuity**:
在多级微服务调用链中，当下游中间某个服务未发布灰度节点而触发降级至基线后，仍保留原始流量标签并在后续向外出站调用中重新回升至目标灰度泳道的穿透保持语义。
_Avoid_: 跨跳穿透, 标签保留, 泳道回升, 跨级灰度

**Sticky Canary Partitioning**:
基于 `MurmurHash3` / 一致性哈希算法，以用户 ID 或客户端 IP 为哈希种子源的百分比流量抽样切流机制，确保同一业务实体在多次请求中始终稳定命中同一泳道。
_Avoid_: 随机分流, 比例切流, 随机抽样

**Resilient Fallback**:
当目标服务实例列表中不包含匹配标签的灰度实例时，调度引擎自动平滑回退至基线稳定实例并记录告警日志的生产级高可用容灾兜底策略。
_Avoid_: 兜底路由, 降级重试, 找不到节点回退

**Strict Lane Isolation**:
在金融交易或关键隔离场景下，当请求携带灰度标签但在下游未命中对应灰度实例时，立即抛出受管业务异常并 Fail-Fast 阻断请求的强隔离策略。
_Avoid_: 强行报错, 隔离中断, 熔断拦截
