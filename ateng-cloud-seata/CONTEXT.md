# Seata Context

分布式事务协调与数据一致性限界上下文，负责统一纳管微服务分布式事务边界、全局事务（Global Transaction）生命周期驱动、AT / TCC 双核模式协同、TCC 防悬挂与幂等业务防卫屏障（TCC Fence）、跨进程 XID 对称透传、异步线程池快照穿透、多租户内部表排除与 TC 断连刚性熔断防卫。

## Language

**Global Transaction**:
跨越多个微服务与多个数据源协同执行的分布式事务逻辑执行单元，由全局事务唯一标识符（XID）在全链路唯一标识并驱动两阶段提交或回滚。
_Avoid_: 分布式事务上下文, 全局任务, 跨库事务, 分布式批处理

**Transaction Coordinator**:
独立维护全局事务执行状态、分支事务注册、全局锁裁决与驱动两阶段提交/回滚决策的核心事务中枢服务（TC）。
_Avoid_: 协调服务, 事务服务端, Seata Server, 事务控制台

**Transaction Manager**:
开启、提交或回滚全局事务的业务发起端组件（TM），负责界定全局事务范围并在事务异常时决定是否发起全局回滚。
_Avoid_: 事务发起方, 全局事务切面, TM 客户端, 事务控制类

**Resource Manager**:
管理分支事务物理资源（如通过数据源代理或 TCC 业务接口），向 TC 注册分支事务并驱动一阶段提交与二阶段回滚的执行端组件（RM）。
_Avoid_: 分支事务管理器, 资源端, RM 客户端, 驱动代理

**TCC Fence**:
依托本地事务日志表自动记录分支事务推进状态，在 TCC 两阶段执行中刚性拦截“空回滚 (Empty Rollback)”、“业务悬挂 (Hanging)”与“重复提交 (Idempotent)”的受管业务防卫机制。
_Avoid_: TCC 过滤器, 防悬挂切面, 幂等校验表, 防重切面

**XID Propagation**:
将全局事务唯一标识（XID）经由 HTTP Feign 请求标头（`TX_XID`）及 Dubbo RpcContext 附件跨进程透明透传，并在提供端对称恢复绑定与入栈/出栈确定性解绑的生命周期机制。
_Avoid_: 事务头传递, XID 注入, 跨服务传参, 事务标记透传

**Global Lock**:
在非分布式事务或纯读/轻量写操作中，仅向 TC 校验或临时申请全局行级排他锁而不生成 undo_log 分支的轻量防脏写锁机制。
_Avoid_: 分布式行锁, 全局排他锁, 事务防撞锁

**Async XID Propagation**:
通过异步上下文快照机制，在跨线程并发（如线程池或异步执行器）中安全捕获、传递并在子线程任务结束时幂等清理 RootContext XID 的全生命周期机制。
_Avoid_: 线程池传参, 异步 XID, 子线程事务, 异步传递

**Tenant Table Exclusion**:
在行级多租户拦截机制中，强制将分布式事务内部系统表（如 `undo_log` 与 `tcc_fence_log`）排除在租户过滤注入范围之外的防御性机制。
_Avoid_: 忽略租户, 租户白名单, 内部表放行, 租户过滤短路

**Fail-Fast Outage Defense**:
在分布式事务协调器（TC）发生网络分区或宕机不可达时，立即阻断全局事务并抛出受管业务异常，坚决杜绝无协调保障下单边数据落库的金融级防卫策略。
_Avoid_: 事务降级, 忽略报错, 本地事务保底, 弱一致执行
